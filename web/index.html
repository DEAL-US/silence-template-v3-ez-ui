My application

A project created with silence new. Silence serves this web app at /, the API at /api and the admin panel at /admin/.

Admin panel API

Where things are

  • web/: the pages of this web app, starting with this index.html.
  • web/css/app.css: your own styles, after the ones of ez-ui (web/ez-ui/, which is not modified).
  • web/js/api/_auto/: the JS API that Silence generates with the endpoints, to call them from your pages.
  • sql/: the scripts that create the database and load its data.

Next steps

In the admin panel: connect to the database and load it, generate the endpoints, give each one its access and run their tests. Then replace this page with the first one of your app.
